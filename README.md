# 轮胎内壁点云异常检测

本仓库封装课程研究中选定的一个最终方案：**RRF 主筛候选 + 原始点云剖面复判 + 冻结 DINOv2 的原样裁剪 MLP + 候选级融合分类头 + 分带局部显著性补扫**。

目标是在有限的候选预算内，给出疑似气泡、疑似附着物和待复核位置，供人工结合扫描与剖面进一步检查。仓库只保留这一方案的代码、选定权重、验证记录与汇报材料，不包含其他网络结构、增广版本或模型选型实验。

## 已验证结果

结果来自现有 **10 条轮胎、10 处已标气泡、6 处已确认附着物**。下表是同一最终方案的两种候选预算。

| 设置 | 每胎候选数 | 命中已标气泡 | 命中已确认附着物 |
| --- | ---: | ---: | ---: |
| 主筛 | 20 | 9/10 | 6/6 |
| 主筛加局部补扫 | 44 | 10/10 | 6/6 |

补扫固定追加 24 个位置。已有整胎评分图时，原验证记录中的补扫增量耗时平均 **9.97 秒/胎**，范围为 7.94–15.28 秒；平均新增 **7 条疑似气泡候选/胎**。该时间包括补扫提议、原点云局部复判和 MLP 评分查询，不含点云展平、主筛与重新生成整胎评分图。

`G6B1F56073` 是这批数据中唯一经补扫找回的已标气泡。所有统计按不同已知缺陷实例计数，重复命中的候选不会增加缺陷数量。

## 现实条件与使用约束

- **缺陷样本少。** 目前只有十胎数据；附着物仅确认了六处。模型冻结预训练骨干，只训练小型预测头和融合头，以减少需学习的参数。
- **标注不完整。** 六处附着物来自已发现候选的人工确认，没有完整覆盖所有附着物。未标区域在训练中只作低权重项；未核实候选保留“疑似”或“待复核”身份。
- **验证仍限于这批数据。** 训练、规则开发与补扫验证使用了同批轮胎。5 折按胎隔离，每折为 6 条训练胎、2 条验证胎、2 条测试胎。当前记录不能给出独立新胎表现、实际误报率或附着物总体召回率。
- **存在人工复核代价。** 补扫新增 70 条疑似气泡，其中 69 条未匹配已有气泡标注，尚未完整核实；这些数量不是已确认误报数。
- **输入条件固定。** 当前实现面向本项目的有序扫描 CSV、毫米单位和对应 BMP 尺寸。展开图使用固定参考带 4096–5119 行及 64 行保护区，需在参考带两侧提供足够的 512 像素图块。参考带的正常性未逐点核验。原数据中的纹理、缺测和多重回波处理约定也沿用此实现。
- **原始数据单独管理。** 大体积 CSV、BMP、整胎数组与特征缓存不进入 Git。仓库中的轻量测量记录可以离线回放结果；处理原始点云需自行放置数据并准备官方骨干。

## 快速运行

以下命令在仓库根目录执行。

### 1 离线回放已保存的最终结果

不需要联网、GPU 或第三方 Python 包：

```bash
python scripts/replay_results.py
```

程序重新计算 200 个主筛候选的折外融合分值与分类，并交叉检查 240 个补扫候选，输出主筛 9/10、补扫后 10/10 和确认附着物 6/6。结果写入 `outputs/replay/`。这是保存分数上的融合推理回放，不重新运行点云展平或 DINOv2。

### 2 从原始扫描运行最终流程

使用独立的 Python 3.10–3.12 环境。依赖范围固定在 NumPy 1.x、SciPy 1.10–1.13 与 PyTorch 2.1–2.5；按本机 CUDA 条件安装 PyTorch，或使用 CPU 版本。

```bash
python -m pip install -e ".[model]"
python scripts/download_backbone.py

python -m tire_anomaly prepare \
  --csv data/raw/sample/0.csv \
  --bmp data/raw/sample/0.bmp \
  --output data/prepared/sample

python -m tire_anomaly infer \
  --prepared data/prepared/sample \
  --fold 0 \
  --device cuda \
  --output outputs/sample
```

以上反斜杠为 Bash 换行写法；PowerShell 中可将命令写成单行。BMP 只用于读取扫描尺寸，推理读取的是原 CSV 与生成的径向数组，不使用标注图像像素或气泡轮廓。

输出 `predictions.json` 和 `candidates.csv`，包含主筛/补扫来源、从0起算的原采样列与扫描行、几何测量、气泡分与类别。移动准备目录后，可用 `--raw-csv` 指定原CSV的新位置。中间数组较大，需要预留内存和临时磁盘空间。`--device cpu` 可用于无 GPU 环境，耗时取决于硬件与扫描大小。

官方骨干下载约 88 MB，SHA-256 在下载与加载时均校验。DINOv2 源码固定在提交 `7764ea0f912e53c92e82eb78a2a1631e92725fc8`。首次完整推理会由 `torch.hub` 获取这份源码；离线使用时可以传入 `--backbone-source` 和 `--backbone-weights` 指向本地缓存。

### 3 检查点的含义

`models/folds/fold0.pt` 至 `fold4.pt` 是**同一最佳架构在五折验证中的五份选定权重**，每折只保留当时选中的那一份。它们不是五种模型，也没有另行训练一个全十胎的 DINO MLP 部署头。

`models/final_model.json` 包含全部可用确认标注拟合的融合头，以及各折融合头、分组和权重校验值。新扫描推理需显式选择 `--fold`，默认使用最终融合头；复现已知轮胎的折外判别时，选择它所属的测试折并传入 `--fusion-head fold`。保存的十胎指标始终来自折外记录，不以最终融合头的全量回放代替。

## 方法

1. 点云展开并保留原扫描坐标映射，生成固定 20 个 RRF 主筛候选。
2. 每个候选回到原点云，在包含候选点的 25×25 窗内读取径向偏差 P95、相邻实测点差 P99 和缺测率。缺测位置不跨缝构造高度差。
3. 冻结 DINOv2 ViT-S/14，将每块径向图的 384 维特征送入共享的 `384 → 128 → 1` MLP，得到整胎气泡评分。
4. 用几何量与气泡评分百分位训练带 L2 正则的逻辑回归。保留几何规则已确定的类别，仅对满足低附着物分值和气泡分条件的待复核候选补充气泡判断。
5. 对冻结的 4 mm 法向/深度几何评分图分带补扫，以局部中位数和 MAD 衡量显著性，追加 24 个候选，并复用点云剖面规则。

关键结构为：

$$q_{ij}=\sigma\left(W_2\operatorname{GELU}(W_1F_{ij}+b_1)+b_2\right),\qquad z_j=\frac{x_j-\mu_j}{s_j},\qquad p_A=\sigma(w^Tz+b).$$

$$Z(p)=\frac{S(p)-\operatorname{median}(B_p)}{\max(1.4826\operatorname{MAD}(B_p),10^{-6})}.$$

其中 `q` 为气泡分，`pA` 为附着物分类分值；`pA` 未进行独立概率校准。局部背景取同带内距候选 48–96 像素的环带；带宽 128 像素，每带至多 40 峰，带内去重 48 像素，与所有已选点去重 96 像素。

完整几何评分保留原 2 mm 支持条件下的有效评分，仅在新增的 2.5 mm 支持位置用冻结的周期背景与标尺补值。这两组阈值属于同一个冻结几何模块，不是另外训练的网络。

## 训练与复现资料

`models/training_protocol.json` 保存选定五折的学习率、轮次、分组与训练条件。`python -m tire_anomaly.training --help` 提供仅训练这一 MLP 的入口，输入为冻结的 DINO 特征、目标掩膜与逐条胎的记录。原样裁剪输入不做翻转或旋转；训练使用低权重未标区域 BCE 加正样本软 Dice，AdamW、批大小 32、最多 20 轮、早停耐心值 5。

安装训练依赖后，`python scripts/refit_fusion.py` 可以用仓库内已确认候选与折外气泡分重新拟合最终融合头，结果写入 `outputs/refit_final_head.json`，不覆盖已保存的最终参数。

原始训练图块与完整标注不随仓库提供，重新训练需准备相同输入。CUDA 与 CPU 数值精度可能产生小幅差异；既有验证记录保留了原始权重和分数用于核对。

```text
src/tire_anomaly/   最终方案的准备、候选、几何、学习、融合和补扫模块
models/            最终融合参数及每折唯一选定的MLP权重
data/replay/       仅该方案的十胎测量记录与折外结果
scripts/           离线回放、官方骨干下载与核对工具
tests/             结果回放和算法边界的回归检查
docs/              汇报PPT、PDF报告、逐页讲稿与代码来源映射
```

测试：

```bash
python -m unittest discover -s tests -v
```

发布前已核对：200 个主筛候选与 240 个补扫位置均与原记录一致，最终融合头重新拟合的参数完全一致；五折权重均能加载并完成预测。另对 `G6B1F56073` 重新运行 DINO 评分、主筛、原 CSV 剖面复判、几何评分与补扫，20+24 个候选的位置和类别全部一致，并找回已标气泡。该次检查复用了已展平的径向数组，完整推理耗时约 202 秒，与上文“已有评分图时”的补扫增量耗时口径不同。详见 [候选与几何核对](docs/kernel_validation.json)、[融合头核对](docs/fusion_refit_validation.json) 与 [整胎推理核对](docs/full_pipeline_validation.json)。

预训练特征基础：[DINOv2 官方仓库](https://github.com/facebookresearch/dinov2)、[DINOv2 论文](https://arxiv.org/abs/2304.07193)。官方 DINOv2 源码采用 Apache 2.0 许可，遵循其上游说明；本仓库不重复提交官方骨干二进制。
